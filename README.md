# 高校数学 インタラクティブツール

**https://soh-arch.github.io/math-tools/**

高校数学（数学I・A・II・B・III・C）の全単元について、係数や点を自分で動かしながら
「何が変わって何が変わらないか」を確かめられる教材です。
授業での提示、家庭教師での説明、高校生の自習を想定しています。

## つかいかた

上のリンクを開き、単元を選ぶだけです。インストールも登録も要りません。

- **スライダーや点をドラッグする** と、グラフ・図形・数値が同時に変わります。
- **「拡大表示」** を押すと文字と図が大きくなり、プロジェクタでの投影に向いた表示になります。
- **ページ上部のタブ** で小単元を切り替えられます。表示中のタブは URL に残るので、
  見せたい画面をそのままブックマークしたり生徒に送ったりできます。
- **各タブの下の「見方」** に、動かして確かめてほしい要点をまとめています。
  予想してから動かすのがコツです。

ネットワークのない教室でも使えます。リポジトリを ZIP でダウンロードして展開し、
`index.html` をブラウザで開けば、そのまま同じように動きます（数式表示に必要なものは同梱済みです）。

## 使う場面ごとのヒント

- **授業で見せる** — 「拡大表示」にして、スライダーを 1 つだけ動かします。
  動かす前に「どこが変わると思う？」と問いかけると、生徒の予想と結果を突き合わせられます。
- **家庭教師で使う** — 操作を生徒に任せ、読み取り欄の数値が図のどこに対応しているかを
  説明してもらうと、どこまで分かっているかがはっきりします。
- **自習で使う** — 「見方」に書かれた問いに自分で答えてから動かします。
  ずれたところが、そのまま復習すべき場所になります。
